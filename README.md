# hikari UI

Tailwind CSS をベースにした、個人向けの HTML コンポーネント集です。

## 使い方

ブラウザで index.html を開いてください。Tailwind CSS とフォントは CDN から読み込むため、インターネット接続が必要です。Tailwind Play CDN は試作向けです。本番利用時は Tailwind をビルドして CSS を配布してください。

## テーマの変更

style.css の先頭にある :root の色や角丸の変数を変更すると、全体の雰囲気を調整できます。コンポーネントの HTML と関連する CSS をコピーして利用できます。
